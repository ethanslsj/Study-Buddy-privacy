隐私政策 · Study Buddy

生效日期：2026 年 9 月 25 日　|　适用于 Windows 桌面版

你的学习数据只存在你自己的电脑里，我们没有任何服务器，也看不到任何数据。 只有在你主动配置了第三方 AI 接口之后，应用才会把你输入的问题发送给你所选的那家服务商。

数据存储在哪里

数据类型存放位置
知识卡片、任务、复习记录、专注记录、AI 对话历史%APPDATA%\Study Buddy\custom.db（本机 SQLite 文件）
AI 接口配置（baseUrl / 模型 / API Key）%APPDATA%\Study Buddy\settings.json（本机文件）

两者都保存在本机，卸载应用时可选择保留。我们不上传、不同步、不备份这些内容到任何外部位置。

AI 问答与网络访问

AI 问答功能默认处于未配置状态。在你于「设置」中填写接口地址与 API Key 之前，该功能不会发出任何外部网络请求。

  • 一旦你配置了接口，你输入的问题、以及相关学科上下文会被发送到你指定的那家服务商（例如你填入的智谱 / DeepSeek / OpenAI / 硅基流动等地址）。
  • 这部分数据的处理方式受该服务商自己的隐私政策约束，请在配置前自行确认你信任该服务商。
  • 你填写的 API Key 只保存在本机；应用界面回读时只显示「是否已填写」，不会回显明文。
  • 删除配置即可完全停止 AI 相关的网络访问。

除上述情况外，应用仅在本机 127.0.0.1 上启动一个内置服务用于界面通信，不对外发起请求。

我们承诺

  • 不收集个人信息：无需注册、无需登录，我们不索取姓名、邮箱或手机号。
  • 不使用分析或统计 SDK：程序中不含任何第三方埋点、用户行为分析组件。
  • 不上报崩溃信息：未接入崩溃上报服务，运行错误仅输出到本机日志。
  • 不采集遥测：已在启动时设置 NEXT_TELEMETRY_DISABLED=1，禁用内置框架的遥测。
  • 不读取与学习无关的文件：应用只读写自己的数据库与配置文件。

儿童隐私

本产品面向一般学习人群，不专门面向 13 岁以下儿童，也不会故意收集儿童的个人信息。由于所有数据均保存在用户本机且我们无法访问，我们不具备识别或收集儿童信息的能力。

你的控制权

  • 在应用内可直接删除任意卡片、任务、对话与专注记录。
  • 卸载应用会移除程序；数据库文件会保留在你本机，可自行删除 %APPDATA%\Study Buddy\ 目录。

政策变更

若未来功能调整导致数据处理方式发生变化，我们会更新本页并修改顶部的生效日期。
